# CV Builder cho Data Analyst

Web nội bộ cho học viên: điền dữ liệu thô theo khung "CV & Linkedin", AI viết CV gốc, tùy biến theo từng JD, xuất PDF/DOCX.

Stack: Next.js 15 · Tailwind 4 · Supabase · Anthropic SDK · Playwright (PDF) · Vercel.

## Chạy local

```bash
cp .env.example .env.local   # điền key
npm install
npm run dev
```
